Object-Oriented Programming (OOP) in JavaScript

1. JavaScript is prototype-based, NOT class-based
2. JavaScript introduced the class keyword in ES6 (2015), but it is primarily syntactic sugar . This means that while you can write code that looks like Java or C++, the underlying engine still uses prototypes to handle inheritance and object creation 
3. oop is programming paradigm  (A programming paradigm is a way of thinking about and organizing code to solve problems.)
4. object are just collection of properties and methods
5. Main Reasons We Use OOP in JavaScript 
    1. Better Code Organization
    2. Reusability (Inheritance) ,
    3. Encapsulation (Data Safety)
    5. Scalability (Large Projects)
6. parts of OOP
    1. Object literal (The simplest way to create an object. No class, no constructor Just a direct object)
    2. Constructor Function (Used to create multiple objects.)
    3. Prototypes (Methods are shared (memory efficient))
    4. Classes (ES6) (Modern and clean syntax)
    5. Inheritance (Reusing properties from another class)
7. 4 pillars OF OOP
    1. Abstraction (Hiding complex details and showing only essential features)
    2. Encapsulation (Wrapping data and methods together + restricting direct access)
    3. Inheritance (One class can use properties/methods of another)    
    4. Polymorphism (Same method behaves differently)
